# Postman walkthrough - Dexterity Arsenal (Member 2)

## A. Setup (2 minutes)
1. Start Postgres, then the backend: `cd backend && npm run setup && npm run dev`
   (run `npm run seed` any time to reset demo data).
2. Open Postman -> **Import** -> choose `Dexterity-Arsenal.postman_collection.json`.
3. The collection variable **`baseUrl`** is `http://localhost:4000` (change it in the collection's *Variables* tab if needed).
   No environment is required: tokens and IDs are stored automatically as *collection variables*.
4. Click the collection -> **Run** (Collection Runner) -> **Run Dexterity Arsenal API**. All requests should be green.
   Or click through requests one by one using the order below.

## B. How the "connection" works
Every request that creates something saves its id for the next one (see the *Tests* tab):

```
Login learner  ──► learnerToken            Login instructor ──► instructorToken
Create ONLINE slot ──► slotId ──► Book slot ──► bookingId ──► Cancel booking
Course detail ──► basicPlanId / proPlanId / maxPlanId ──► Checkout ──► subscriptionId ──► Confirm ──► Change plan ──► Cancel
```
Authenticated requests use **Authorization -> Bearer Token -> `{{learnerToken}}`** (or instructor/admin).

## E. Folder 3 - Admin & notifications
Admin lists unverified instructors, approves one (learner calling this gets **403**), then the learner's bell (`/notifications`) shows events generated by the steps above.

## F. Try these by hand (good for your demo)
* **Race condition:** duplicate the "Book the slot" request, log in as different learners and fire both quickly - exactly one succeeds.
* **Perk gating:** subscribe to **Basic** instead of Pro: `GET .../resources` returns `canDownload:false` and `fileUrl:null`.
* **Frontend + Postman together:** book a slot in the browser, then call `GET /sessions/slots/mine` as the instructor in Postman - the booking and attendee appear instantly.
